# Free tools ideas

Printables and templates. Each should be useful with nothing but paper and a pen.

| Tool | Search phrase | Notes |
| --- | --- | --- |
| Commonplace book page | commonplace book template | Heading, quote, source, and a line for "why it matters". Link from the commonplace book post. |
| Weekly review sheet | weekly review template | The weekly review questions on one page. Pairs with the weekly review questions post. |
| Franklin virtue chart | benjamin franklin virtue chart, 13 virtues chart | Franklin's own grid: 13 virtues by 7 days, one virtue in focus each week. Check his layout in the autobiography. |
| Reading notes card | book notes template | One idea per card, a question on the front, for the "remember what you read" system. Link from that post. |
