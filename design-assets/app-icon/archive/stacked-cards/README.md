# Archived icon: stacked cards (Ink on white)

The app icon and site logo used until October 2026: two stacked note cards, the front one with the loop arrow and line. Replaced by the 3D thought bubble in `../gen.cjs`.

- `light.svg`, `dark.svg`, `tinted.svg`: the 1024 px sources (iOS appearance slots).
- `AppIcon*.png`: the PNGs that shipped in `AppIcon.appiconset`.
- `gen.cjs`: the old generator (`node gen.cjs` writes the SVGs, plus an HTML wrapper for each, into the current directory).
